# AF/SS Seeder Update - No Inventory/Stock Seed

Date: 2026-06-23

Changes:

- Removed AF/SS default product, vendor, brand, category, stock, stock movement and product detail seeding from the web seeder.
- `IncludeProducts` is now ignored by the API and defaults to `false`.
- AF/SS page no longer offers product/opening-stock seeding.
- Employee and Manager salesman default creation now runs only for the Smart Menswear profile/store.
- Aadwika Fashion MBO and Aadwika Fashion - Shalini MBO seed runs skip employee/salesman creation.

Reason:

Inventory and stock should be imported/entered through actual purchase/import flows, not generated by AF/SS defaults. Employees should belong to Smart Menswear only for the default store structure.
