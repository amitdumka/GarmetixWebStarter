# Price Tag Purchase Integration

Price tag printing can now be launched directly from purchase inward and posted purchase import workflows.

## Entry points

- Purchase → Import Supplier Invoice → posted draft → **Print tags**
- Purchase → Purchase Invoices → row action **Tags**
- Purchase receipt modal → **Print price tags**
- Direct URL with purchase inward id or import batch id

## Tag sizes

- 50 × 30 mm
- 50 × 25 mm

## Printer options

- Browser / driver print for USB desktop thermal printers.
- TSPL command download for Bluetooth/mobile thermal printer apps or bridge utilities.
