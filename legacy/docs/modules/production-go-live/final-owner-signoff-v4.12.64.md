# Final Owner Sign-off

Route: `/final-owner-signoff`

This page prepares the owner declaration and signature sheet after the go-live gate is ready.

## Recommended flow

1. Run Production Go-Live Master Acceptance.
2. Clear Critical issues.
3. Export go-live CSV.
4. Open Final Owner Sign-off.
5. Enter owner name/mobile if needed.
6. Export CSV and use **Print / PDF**.
7. Owner/accountant signs and stores the signed proof outside the app.
