# Final Accounts CA Review Guide

The CA workspace is for review adjustments, comments, attachments, report versions, and evidence packages. BS-13 does not grant default CA access to accountant or remote accountant roles; access must be explicitly designed before production use.

## Review Flow

1. Request the accountant reconciliation export and trial balance.
2. Add CA adjustments as drafts with balanced debit and credit lines.
3. Submit adjustments for review.
4. Approve only after evidence and comments are attached.
5. Post approved adjustments to the General Ledger.
6. Use auto-reversal only when the next-period reversal date is known.
7. Export the CA package and verify the package checksum.

## Report Versions

Draft, submitted, and review adjustments remain provisional. Approved adjustments are adjusted. Posted and reversed adjustments are final. The report must continue to show unaudited status unless a later statutory audit workflow is added.
