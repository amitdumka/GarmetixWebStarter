# Final Accounts Reconciliation Runbook

Reconciliation proves that source modules and Final Accounts journals agree for the selected period and scope.

## Steps

1. Select company, optional store group, optional store, and fiscal period.
2. Run reconciliation summary.
3. Export reconciliation detail.
4. Investigate unmapped, unposted, duplicate, and drifted source rows.
5. Re-run posting preview after fixes.
6. Reconcile General Ledger, Trial Balance, Profit and Loss, Balance Sheet, and Cash Flow outputs.
7. Save final exports and the reconciliation summary with the close evidence.

## Acceptance

Trial Balance debit and credit totals must match. Known differences must be documented before close. Cross-company rows must not appear in reconciliation exports.
